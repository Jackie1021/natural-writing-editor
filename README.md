# Natural Writing Editor

一个单页的写作修改小工具：粘贴文字，选择模式（自然化 / 润色 / 学术 / 精简），用 Claude 改写成自然、清楚、保留原意和个人口吻的文字。

- 纯静态页面，无需后端，可直接用 GitHub Pages 托管
- 使用你自己的 Anthropic API Key，只保存在本机浏览器 localStorage
- 默认模型 `claude-opus-5-5`，可切换 `claude-sonnet-5-5`

## 使用

打开 GitHub Pages 地址（或直接双击本地 `index.html`），填入 API Key，粘贴原文，点「改写」。

> 用于课程作业时，请遵守所在学校 / 课程关于 AI 工具使用和披露的规定。
